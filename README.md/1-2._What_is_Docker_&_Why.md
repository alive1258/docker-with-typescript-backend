Docker হলো একটি containerization platform, যার সাহায্যে আমরা application এবং সেটি চালানোর জন্য প্রয়োজনীয় dependencies, libraries, configuration ইত্যাদি একসঙ্গে প্যাকেজ করে যেকোনো compatible environment-এ চালাতে পারি।

সহজভাবে বললে, Docker নিশ্চিত করতে সাহায্য করে যে তোমার application তোমার computer, testing server এবং production server-এ একইভাবে কাজ করবে।

## 1. Why Do We Need Docker?

ধরো, তুমি Node.js, NestJS এবং PostgreSQL দিয়ে একটি backend application তৈরি করেছ।

তোমার computer-এ সবকিছু ঠিকভাবে চলছে। কিন্তু অন্য developer-এর computer-এ application চালালে error দেখাচ্ছে।

- তোমার Node.js version এক, অন্যজনের version আলাদা।
- তোমার PostgreSQL installed আছে, অন্যজনের নেই।
- Environment variables ও dependencies ঠিকভাবে configure করা নেই।
- Production server-এ application চালাতে গিয়ে compatibility সমস্যা হচ্ছে।

এই সমস্যাগুলো সমাধানে Docker সাহায্য করে।

Docker architecture-এর প্রধান অংশ:

## 4. Install Docker and Run Your First Container

Windows 11-এ Docker শেখার জন্য সাধারণত Docker Desktop with WSL 2 ব্যবহার করতে পারো।

Official website: Download Docker Desktop

Installation শেষে terminal বা PowerShell খুলে নিচের commands চালাও।

Step 1: Check Docker installation

```
docker --version
```

Step 2: Check Docker Engine

```
docker info
```

Step 3: Run your first container

```
docker run hello-world
```

এই command যা করবে:

1. Local machine-এ `hello-world` image আছে কি না দেখবে।
2. না থাকলে Docker registry থেকে image download করবে।
3. Image থেকে একটি container তৈরি করে চালাবে।
4. সফল হলে একটি confirmation message দেখাবে।

Step 4: List containers

```
docker ps
```

এটি বর্তমানে running containers দেখাবে। `hello-world` container শেষ হয়ে যাওয়ায় এখানে নাও দেখা যেতে পারে।

সব containers দেখতে:

```
docker ps -a
```

## 5. Docker vs Virtual Machine

Dockerize YOLO11: Streamline Model Deployment | Ultralytics

Docker Container

- Host kernel share করে।
- সাধারণত দ্রুত start হয়।
- তুলনামূলক কম overhead।
- Application isolation দেয়।

Virtualization and Containerization: Which one to pick?

Virtual Machine (VM)

- Guest OS চালায়।
- সাধারণত বেশি resources প্রয়োজন।
- Boot হতে বেশি সময় লাগতে পারে।
- আলাদা OS environment দেয়।

মনে রেখো, Docker container সম্পূর্ণ Virtual Machine নয়। এটি host operating system-এর kernel ব্যবহার করে isolation প্রদান করে।

## 6. Real-World Example: NestJS + PostgreSQL

ধরো, তুমি একটি backend API তৈরি করছ। Docker ব্যবহার করে PostgreSQL চালাতে পারো—নিজের Windows machine-এ PostgreSQL সরাসরি install না করেও।

```
docker run -d \
  --name my-postgres \
  -e POSTGRES_USER=admin \
  -e POSTGRES_PASSWORD=secret123 \
  -e POSTGRES_DB=myapp \
  -p 5432:5432 \
  postgres:17
```

এটি PostgreSQL 17-এর একটি container চালাবে।

- `d` — background-এ চালায়।
- `-name` — container-এর নাম নির্ধারণ করে।
- `e` — environment variables সেট করে।
- `p 5432:5432` — host-এর port 5432-কে container-এর port 5432-এর সঙ্গে যুক্ত করে।
- `postgres:17` — ব্যবহৃত image ও version নির্ধারণ করে।

এটি একটি learning example। বাস্তব production environment-এ password source code বা command history-তে না রেখে secrets management ব্যবহার করবে।

Container বন্ধ করতে:

```
docker stop my-postgres
```

আবার চালু করতে:

```
docker start my-postgres
```

Container মুছে ফেলতে:

```
docker rm -f my-postgres
```

সতর্কতা: container মুছে ফেললে তার ভেতরে সংরক্ষিত database data হারাতে পারো, যদি persistent volume ব্যবহার না করে থাকো।

## 7. Why Should a Backend Developer Learn Docker?

| সুবিধা      | বাস্তব ব্যবহার                                         |
| ----------- | ------------------------------------------------------ |
| Consistency | Development ও production environment-এর পার্থক্য কমানো |
| Portability | বিভিন্ন compatible environment-এ application চালানো    |
| Isolation   | একাধিক application-এর dependencies আলাদা রাখা          |
| Easy setup  | নতুন developer-এর environment দ্রুত প্রস্তুত করা       |
| CI/CD       | Automated testing ও deployment workflow তৈরি করা       |
| Scalability | প্রয়োজন অনুযায়ী একাধিক container instance চালানো       |

## 8. Important Docker Commands

| Command                     | কাজ                     |
| --------------------------- | ----------------------- |
| `docker --version`          | Docker version দেখা     |
| `docker pull nginx`         | Image download করা      |
| `docker images`             | Local images দেখা       |
| `docker ps`                 | Running containers দেখা |
| `docker ps -a`              | সব containers দেখা      |
| `docker run nginx`          | Nginx container চালানো  |
| `docker stop <name>`        | Container বন্ধ করা      |
| `docker start <name>`       | Container চালু করা      |
| `docker logs <name>`        | Container logs দেখা     |
| `docker exec -it <name> sh` | Container-এর shell খোলা |
| `docker rm <name>`          | Container মুছে ফেলা     |
